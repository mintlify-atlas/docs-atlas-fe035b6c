## Quick Start

Get your Istio control plane running in minutes:

<Steps>
  <Step title="Install the Operator">
    Deploy the Sail Operator to your Kubernetes cluster
    ```bash
    kubectl apply -f https://github.com/istio-ecosystem/sail-operator/releases/latest/download/install.yaml
    ```
  </Step>
  
  <Step title="Create an Istio Resource">
    Deploy your Istio control plane with a simple manifest
    ```yaml
    apiVersion: sailoperator.io/v1
    kind: Istio
    metadata:
      name: default
    spec:
      namespace: istio-system
      version: v1.29-latest
    ```
  </Step>
  
  <Step title="Verify Installation">
    Check that your control plane is healthy
    ```bash
    kubectl get istio -A
    ```
  </Step>
</Steps>
